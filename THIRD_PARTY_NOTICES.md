# Third-party components

The dashboard embeds public geographic geometry and needs no map service.

- D3: ISC license, retained at `vendor/D3-LICENSE.txt`.
- TopoJSON client: ISC license, retained at `vendor/TOPOJSON-LICENSE.txt`.
- World Atlas 2.0.2: ISC license, retained at `vendor/WORLD-ATLAS-LICENSE.txt`.
- World Atlas boundaries derive from public-domain Natural Earth geographic data.
- Playwright is a development-only dependency under Apache-2.0; it is not embedded in reports.

Only geography, executable code and license text are vendored. No customer source records are included.
